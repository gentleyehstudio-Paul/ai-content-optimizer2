# 水墨光紋引擎 Ink Light Flow

即時攝影機驅動的水墨光紋特效 + 視頻處理，純前端（HTML + Canvas 2D，無外部函式庫、無需付費 API）。

## 功能

### 📷 即時鏡頭模式
實時分析攝影機畫面的明暗梯度，即時生成水墨光紋效果。

**特點**：
- 前置/後置相機自動回退機制
- 可即時切換相機
- 實時錄影並下載為 MP4/WebM
- 截圖保存到相簿

### 🎬 視頻處理模式 (NEW)
上傳既有視頻文件，將調好的水墨效果參數應用到每一幀，生成新視頻。

**特點**：
- 支援 MP4、WebM、MOV 等格式
- 逐幀處理，顯示進度條
- 保留原視頻幀率和解析度
- 可取消處理過程
- 輸出 MP4（H.264）或 WebM（VP9）

## 原理

### Sobel 梯度分析
1. 每幀將視頻/鏡頭畫面縮小取樣（96×54）
2. 計算灰階亮度與前一幀的差異
3. 用 Sobel 運算子計算局部亮度梯度
4. 沿梯度垂直方向（等亮度線）生成流動筆觸

### 渲染最佳化
- 畫布不完全清除，疊加半透明底色形成拖尾
- 小尺寸離屏畫布 + 單次模糊（避免逐筆 shadowBlur 卡頓）
- 深色主題用 `lighter` 疊加，宣紙用 `multiply`

### 參數調控
所有參數可即時調整：
- **敏感度**: 梯度變化偵測靈敏度
- **墨韻延遲**: 拖尾效果長度
- **筆觸長度**: 單筆墨紋的長度
- **粒子密度**: 每幀生成的筆觸數量
- **主題**: 墨夜光紋 / 宣紙水墨 / 極光水墨

## 使用方式

### 安裝
```bash
cd ink-light-effect
python3 -m http.server 8080
# 開啟 http://localhost:8080
```

### 即時鏡頭
1. 點「📷 即時鏡頭」分頁
2. 點「啟動鏡頭」，允許攝影機權限
3. 調整參數看效果
4. 點「● 開始錄影」錄制視頻
5. 錄好後點「停止」，再點「儲存 / 分享影片」下載

### 視頻處理
1. 點「🎬 視頻處理」分頁
2. 點「📁 選擇視頻」上傳 MP4/WebM 文件
3. 調整敏感度、拖尾、筆觸、密度參數
4. 點「⚙️ 開始處理」開始逐幀處理
5. 進度條顯示已處理幀數
6. 完成後點「💾 儲存 / 分享影片」下載

## 錄影與下載

### 影片格式
程式優先輸出 MP4（H.264），瀏覽器不支援時退回 WebM（VP9）。

### 手機儲存
- **iOS Safari（新版）**: Web Share API 跳出分享面板 → 存到相簿
- **Android Chrome**: 直接下載到「下載」資料夾
- **iOS Safari（舊版）**: 開新分頁播放，長按「儲存影片」

### 位元率
程式自動估算位元率（6–40 Mbps），避免瀏覽器預設保守值（2.5 Mbps）。

## 技術架構

**核心算法**:
- Sobel 運算子 (梯度計算)
- 實時亮度差異分析
- 筆觸粒子生成與衰減

**渲染引擎**:
- Canvas 2D (main + glow buffer)
- 混合模式 (lighter / multiply)
- 模糊濾鏡 (filter: blur)

**串流錄制**:
- canvas.captureStream() (逐幀擷取)
- MediaRecorder API (編碼)
- Web Share API (手機分享)

## 效能注意

- 大視頻檔（>1GB）需要足夠的瀏覽器記憶體
- 4K 視頻處理可能較耗時（純 JS 單線程）
- 建議全螢幕模式以獲得最高解析度
- 行動設備上視頻處理會佔用較多資源

## 參數預設值

```
敏感度:    14  (範圍: 2-40, 越小越敏感)
墨韻延遲:   9  (範圍: 2-30, 越小越長)
筆觸長度:  26  (範圍: 4-60)
粒子密度:   5  (範圍: 1-10)
主題:    墨夜光紋
```

## 故障排除

### 無法啟動鏡頭
- 確認在 HTTPS 或 localhost 環境
- 檢查瀏覽器是否要求攝影機權限
- 嘗試切換相機（前置 ↔ 後置）

### 視頻處理很慢
- 關閉其他標籤頁/應用以釋放記憶體
- 使用較小的解析度視頻
- 嘗試在桌面上而非行動設備處理

### 錄影或視頻無法儲存
- iOS 用戶：允許應用存取相簿
- 檢查瀏覽器是否支援 Web Share API
- 嘗試使用新版瀏覽器
